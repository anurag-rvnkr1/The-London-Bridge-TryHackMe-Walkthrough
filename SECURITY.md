# Security Policy

This repository documents an authorized TryHackMe training environment..

## Scope

The techniques described here are intended for the lab target and similarly authorized systems only.

## Sensitive material

Challenge flags, passwords, private-key contents, session secrets and other reusable authentication material are intentionally redacted from the public repository..

## Reporting

The repository itself is documentation, not a production application. Please do not submit unrelated vulnerability reports against third-party systems using the techniques in this write-up..
